What Labby does

Everything for your homelab map

One dashboard for all your infrastructure. From bare-metal servers to containerized apps — add it, connect it, visualize it.

🖥️

Resource Tracking

Hardware, VMs, LXCs, Apps and Networks with rich metadata — OS, CPU, RAM, disks, notes and links.

🌳

Topology Views

Tree view and interactive Graph view visualize hosting relationships between every resource.

🗄️

Rack View

Create locations and racks. Drag components into front and rear rack slots and link them to Labby resources.

🌐

IP View

Dedicated IP address view grouped by subnet. Live search by IP, hostname or port. Color-coded networks.

📡

Live Status Checks

Optional auto-ping for IPs and auto-check for URLs. Online / Offline / Maintenance status per resource.

🎨

10+ Themes

Built-in Light, Dark, Ocean, Nord, Grape and more — plus a full custom theme editor with export support.

💾

Server-Side Storage

Data lives on the server, shared across all browsers and devices. Export / import JSON backups anytime.

📱

Mobile Optimized

Full-screen views and bottom navigation on mobile and tablet. Same features, smaller screen.

🔍

SEO Optimized

Clean semantic HTML, meta tags, Open Graph and Twitter Card support — ready to be indexed and shared right out of the box.

Deployment

Two ways to use Labby

Pick the version that fits your needs. Both run under my-labby.com.

🚀

Demo — /demo/

Try Labby instantly with no setup. Data is stored in your browser only — nothing is saved to a server. Perfect for exploring features.

Open Demo
🔒

App — /app/

Full Labby with persistent server-side storage. Data survives restarts and is shared across all your devices and browsers. SSO-ready.

Open App

Self-Hosting

1

Clone the Labby repository

2

Enter the Labby Neue Webseite folder

3

Run docker compose up — open localhost

git clone https://github.com/techbygiusi/Labby.git
cd "Labby/Labby Neue Webseite"
docker compose up --build -d
